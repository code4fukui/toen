# toen

A simple translator Japanese to English wit [Gemma3:4b](https://huggingface.co/google/gemma-3-4b-it).

## usage

```sh
deno -A toen.js 今日はいい天気
```

## install

```sh
deno install -f --global --allow-import --allow-net=127.0.0.1:11434 toen.js
```

## uninstall

```sh
deno uninstall --global toen
```
